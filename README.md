# 📊 HR Analytics Dashboard (Power BI)

## 📌 Project Overview
This project analyzes employee workforce data using Power BI to uncover insights into employee attrition, salary distribution, performance trends, and workforce demographics.

The dashboard was designed to help HR stakeholders identify retention issues, understand workforce patterns, and support data-driven decision-making.

---

# 🎯 Objectives
- Analyze employee attrition trends
- Identify departments and roles with high attrition
- Evaluate salary and performance patterns
- Understand workforce tenure distribution
- Support HR decision-making with interactive analytics

---

# 🛠 Tools & Technologies
- Power BI
- Power Query
- DAX
- CSV Dataset

---

# 🧹 Data Cleaning & Preparation
The dataset included several real-world inconsistencies:
- Mixed date formats
- Inconsistent text casing
- Trailing spaces in categorical columns
- Missing exit dates for active employees

### Cleaning steps:
- Standardized date formats
- Cleaned and trimmed text columns
- Standardized department and location values
- Handled null values
- Created tenure and attrition-related calculations

---

# 📐 Key DAX Measures
- Total Employees
- Attrition Count
- Attrition Rate
- Average Salary
- Average Performance
- Tenure Calculations

---

# 📊 Dashboard Features
- KPI cards for workforce overview
- Attrition analysis by department, role, and location
- Attrition trend over time
- Tenure-based attrition analysis
- Salary comparison across departments
- Interactive slicers and filters

---

# 📈 Key Insights
- The company has an attrition rate of approximately 19%
- Finance and Sales departments experience the highest attrition
- Employees with 5–10 years tenure show the highest attrition levels
- Attrition trends are relatively consistent across locations
- Average employee performance remains moderate across departments

---

# 💡 Business Recommendations

## 1. Improve Employee Retention
Conduct employee engagement and retention surveys in high-attrition departments to identify turnover drivers.

## 2. Focus on Experienced Employees
Implement career development and recognition programs targeting employees with longer tenure.

## 3. Strengthen Performance Development
Introduce additional training and development initiatives to improve employee performance and satisfaction.
